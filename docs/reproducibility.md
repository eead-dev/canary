# Reproducibility

Run from the repository root with Python 3.12+. These are Windows CMD commands.
Commands producing datasets or results overwrite their designated output files.

## Setup and synthetic demo

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -e ".[comma2k19]"
python -m simulator.generate
python -m canary.inspect datasets\synthetic\can_log.csv
python -m canary.discover datasets\synthetic\can_log.csv datasets\synthetic\speed_reference.csv --value-column speed_kph --top 5 --fit --report results\speed_report.html --output-reconstruction results\speed_reconstructed.csv
python -m unittest discover -s tests -v
```

The core needs only the standard library; the comma2k19 preparation extra supplies
NumPy. Tests use mocked providers and make no live model API calls.

## Challenge suite

```bat
python -m simulator.evaluate_challenges --regenerate
```

Use `--regenerate` on a fresh clone: scenario metadata is retained, but generated
challenge CSVs are ignored. Required baseline CSVs under `datasets/synthetic/`
remain tracked. Challenge generation and evaluation use the existing simulator;
production discovery remains independent of its ground truth.

## Public data: prepare, discover, then validate

```bat
python -m tools.prepare_comma2k19 --download --bus 0
python -m tools.run_comma2k19
python -m validation.validate_comma2k19
```

Preparation downloads checksum-verified arrays from the pinned public example.
Read the [source provenance](../datasets/real/comma2k19/provenance.json) and
[storage limitations](../datasets/real/comma2k19/README.md). The blind runner reads
the generated CAN and GNSS CSVs using nearest alignment, tolerance 0.02 seconds
and minimum 300 aligned samples. It writes results under `results/comma2k19/`.
Only the subsequent validator reads the pinned DBC and compares the saved result;
it does not feed truth back into discovery or rerank candidates.

The curated result has 53,800 frames, 90 IDs and 579 GNSS reference samples. The
0x0AA signal family reconstructs the reference with r ≈ 0.998667, RMSE ≈ 0.448 km/h
and R² ≈ 0.997337. These are in-sample metrics from one capture. The public 15-bit
layout is present at rank 6; affine ambiguity prevents unique layout identification.

## Normal public Ollama CLI

Install Ollama separately and run `ollama serve` in another window if needed.
Cloud authentication belongs to the Ollama installation/session.

```bat
ollama signin
ollama pull gpt-oss:120b-cloud
set "OLLAMA_BASE_URL=http://localhost:11434"
python -m canary.agent_cli ^
  datasets\real\comma2k19\real_can_log.csv ^
  datasets\real\comma2k19\real_speed_reference.csv ^
  --value-column speed_kph ^
  --provider ollama --model gpt-oss:120b-cloud ^
  --alignment nearest --timestamp-tolerance 0.02 --min-samples 300
```

The two [recorded public runs](../examples/comma2k19/README.md) each completed in
five provider turns with zero retries. Future live turns, selected equivalent
layouts, wording, latency and completion depend on the model/provider. Deterministic
math is reproducible for the same observations/configuration; runtime and generated
timestamps are not byte-reproducible. No live API run is required to run tests.

## Evidence integrity

The [manifest](../examples/comma2k19/evidence/manifest.json) records original artifact
paths, byte sizes, SHA-256 hashes and the source snapshot commit. Curated files are
unchanged copies; they are not regenerated by the commands above. The commit records
where artifacts were collected, not an undocumented execution revision. Downloaded
arrays and real CSVs are ignored; licenses and provenance remain public.
